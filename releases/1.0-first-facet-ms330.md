# Project Crystal 1.0 “First Facet”

First public Project Crystal ROM release for the **LG K7 MS330 (MSM8909)**, based on **AOSP Android 5.1.1 / API 22**. Other K7 variants are not qualified.

## What Changed

- Established an AOSP `android-5.1.1_r38` base with the K7's hardware adaptations in dedicated ProjectCrystalROM repositories.
- Builds the **Linux 3.10.108 kernel from source**, including its matching modules. The archived stock device tree is retained.
- Builds **Chromium WebView 95.0.4638.74 from source** as a normal ROM dependency, replacing WebView 39. The built-in browser uses this provider.
- Includes the microG platform/native compatibility adaptations and pinned, original-signed microG packages.
- Includes release-signed **CrystalGram 0.29.1.1820** for Telegram messaging and **BasicSmsReceiver** for incoming SMS notifications/verification codes.
- Restores Qualcomm hardware video encoding/decoding alongside the working camera, audio, radio and wireless stack.
- Ships as a **user build with SELinux enforcing**, authenticated ADB and MTP as the USB default. Early unauthenticated diagnostic USB is removed.
- Adds the supplied Project Crystal boot still, default wallpaper and a complete default dock: CrystalGram, Contacts, All apps, Camera and Browser.
- Preserves installed TWRP recovery during OTA installation.

**1.0 / First Facet is the Project Crystal release version.** Android remains 5.1.1; the platform security patch label remains **2016-07-05**. This release does not claim later complete Android Security Bulletin coverage. WebView 95 is the final Lollipop-compatible milestone, not a current browser engine.

## Hardware Validation

The maintainer confirmed final hardware regression passed, including **MTP file transfer**. Regression coverage includes Wi-Fi, Bluetooth, cellular data, reboot persistence where applicable, camera photos/video and audio input/output. The built-in browser reports active WebView 95. Incoming SMS is accepted for verification-code use. CrystalGram's release APK passed installation, login, chat browsing, appearance/string checks and actual incoming push delivery through microG.

The user-build and enforcing transitions were tested separately before the final image. ADB authentication is enabled in the release configuration; USB debugging is controlled through Developer options.

## Scope and Known Limitations

- **MS330 only.** Do not treat this as a universal LG K7 ROM.
- No voice Dialer is bundled; calling/VoLTE and call audio are outside this release's scope.
- BasicSmsReceiver is receive-only notification/dialog functionality, not a full SMS/MMS inbox or sending app. CrystalGram uses Telegram messaging services.
- SIM changes require a reboot. The inherited CSIM limitation remains out of scope.
- USB OTG, exhaustive GPS/navigation testing and measured battery endurance are not claimed by this release.
- Wallpaper and dock changes are defaults for newly initialized state. Existing user-chosen wallpapers and launcher layouts are preserved.
- No root solution is bundled.

## Installation

Use **TWRP**. Back up your existing installation and data first. For a first installation from stock or a different ROM/signing identity, use a clean data setup; do not assume dirty-flash compatibility across those installations. Flash `ProjectCrystal-1.0-FirstFacet-MS330.zip`, then reboot and allow first-boot app optimization to finish.

The ZIP contains the matching boot image, preserves installed recovery and does not automatically request a data wipe. The separate boot image is supplied for reference/recovery use; a normal ZIP installation already installs it. Cyanogen/AOSP recovery is not a supported installation route.

Verify downloads against `SHA256SUMS`. Release ZIP/boot bytes are identical to the hardware-tested build; only their external asset filenames were changed to the human release name. The existing Peridot ROM signing identity and bundled application release identities are preserved.
